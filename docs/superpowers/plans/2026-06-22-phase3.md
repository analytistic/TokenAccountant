**Hook 行为（`useDashboardData.ts` 实际实现）：**

- `fetchData(isEvent)` — `isEvent=false` 时只获取数据不 push 趋势队列（初始加载），`isEvent=true` 时 push 最新点
- 趋势队列 shift/push 前检查 `latest_trend_point.idx > 队列最后点.idx`，防止重复塞入
- `padTo7Days()` — 前端生成最近 7 天日期，缺失的填零值，保证柱状图固定 7 天
- `isEvent` 参数代替 `useRef`（避免 React StrictMode 双次执行导致的 bug）
- `current_audit` 初始为 null（`prev === null` 时置 null），等 event 触发后才显示
- 组件卸载时显式调用 `unlisten()`（`unlistenRef` 管理）
**关键规则（per PRD/spec）：**
- 初始加载：invoke → 填充 today / daily / ranking（**不含 current_audit**）
- current_audit 初始 = null（等 event 后才显示）
- 趋势队列初始化为 20 个零值（不管 SQLite 有没有数据）
- 收到 audit-tick → 重新 invoke → shift/push 趋势队列 → 更新 current_audit

**组件规格（实际实现）：**

#### TrendChart

- 3 个 SubChart（Input / Cache / Output），垂直排列，flex:1 等分空间
- 审计值趋势线：粗实线 (stroke-width 2.2)，声称值趋势线：淡色实线 (stroke-width 1.5, opacity 0.4)
- 差值区域填充：正向沿声称线 → 反向沿审计线闭合（`fillOpacity 0.12`）
- Y 轴动态范围：`yMin = max(0, dataMin - range*0.1)`, `yMax = dataMax + range*0.15`，下限不低于 0
- 差异率：队列最后一点的 diffRate = (latestClaimed - latestAudit) / latestClaimed × 100%
- 全零时画一条 Y=0 的平直线（不隐藏）
- Legend：审计值（基准）、声称值、差值区域
- 直线段 polyline（不用 Catmull-Rom 避免噪声数据 artifact）

#### ModelPieChart

- 最多 5 个模型扇形，其余归入 Other（5+1 上限）
- 径向双层扇区：R_audit 固定 22px (opacity 0.8)，R_claimed = max(R_audit, R_audit × 声称/审计) (opacity 0.25)
- 白色 0.8px 分隔线从圆心到最外边缘
- 360° 全圆用两个 180° 弧（避免 SVG arc 起点=终点退化）
- 过滤 audit=0 的模型
- Hover 交互：当前扇形不变，其余 opacity 降至 0.1；图例行同步高亮
- 图例布局：饼图(76px) 左 + 图例右，模型名左 + 审计/声称上下排列右
- 8 色调色板，无数据时返回 null

#### BarChart7Day

- 拆分为 **Prefill**（Input+Cache）和 **Output** 两个区域，各自独立 Y 轴
- Prefill 标签右上角，Output 标签右下角
- SVG `preserveAspectRatio="none"` 拉伸填满容器宽度
- X 轴日期标签用 HTML `<div>` 渲染（避免 SVG 非等比缩放压扁字体）
