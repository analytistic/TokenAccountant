### Task 3：后端 — SQL 聚合查询 + 新 Tauri Commands

**Files:**
- Modify: `src-tauri/src/provider/types.rs` — 新增 `AuditSummary` 类型
- Modify: `src-tauri/src/storage/database.rs` — 新增 `get_dashboard_data()`, `list_providers_with_stats()`, `get_provider_detail()` 方法
- Modify: `src-tauri/src/api/commands.rs` — 新增 4 个命令 + 类型定义 + 修改 `list_providers`
- Modify: `src-tauri/src/lib.rs` — 注册新命令

**Interfaces:**
- Produces:
  - `get_dashboard_data` — 返回 `DashboardData`（含 today_summary / model_breakdown / latest_trend_point / daily_breakdown / provider_ranking / current_audit）
  - `get_provider_detail(provider_id, model)` — 返回指定 Provider+Model 的 I/C/O 审计SUM/声称SUM（点模型标签时过滤用）
  - `get_app_config` / `save_app_config` — 读写应用配置
  - `list_providers` 改为返回聚合数据（credibility、audit_summary 等）
- Consumes: `audit_log` 表，不做 schema 变更
- Consumed by: 前端 DashboardPage / ProvidersPage / SettingsPage

**新增类型（放在 api/commands.rs 或新建 api/types.rs）：**

| 类型 | 字段 | 说明 |
|------|------|------|
| `DashboardData` | proxy_status, today_summary, model_breakdown, latest_trend_point, daily_breakdown, provider_ranking, current_audit | 单命令返回所有 Dashboard 数据 |
| `TodaySummary` | total/suspicious requests, 三组 diff_rate/diff_tokens/match_rate | 今日聚合 |
| `ModelBreakdown` | model name, input/cache/output 审计SUM + 声称SUM | 饼图用 |
| `TrendPoint` | idx, I/C/O claimed/detected | 最新一条趋势 |
| `DailyBreakdown` | date string, I/C/O claimed/detected | 近 7 天每日 |
| `ProviderRank` | id, name, url, credibility, 三组 diff_rate | 可信度排名 |
| `CurrentAudit` | audit_passed, I/C/O 审计/声称/差异 | 最新审计 |
| `AuditSummary` | 三种 I/C/O claimed/detected | Provider 卡片用 |
| `AppConfigPayload` | proxy_port, language, auto_start_proxy, dev_mode_enabled... | 读写配置 |

**数据库新增方法：**

1. **`get_dashboard_data()`** — 单次事务中完成：

   | 子查询 | SQL 模式 |
   |--------|---------|
   | 今日汇总 | `COUNT(*), SUM()... WHERE timestamp >= date('now')` |
   | 模型分布 | `model, SUM()... GROUP BY model WHERE timestamp >= date('now')` |
   | 最新趋势点 | `... ORDER BY id DESC LIMIT 1` |
   | 近 7 天 | `date(timestamp), SUM()... GROUP BY date(timestamp) ORDER BY date DESC LIMIT 7` |
   | Provider 排名 | 复用 `list_providers_with_stats()` 取前 N 个 |
   | 最新审计 | `... ORDER BY id DESC LIMIT 1` |

2. **`list_providers_with_stats()`** — 遍历 provider 列表，每条附带 `credibility` + `total_requests` + `suspicious_requests` + `audit_summary`

   - 可信度算法：`max(0, 100 - (I多报率×10 + C多报率×2 + O多报率×5) / 17)`
   - 多报率 = `max(0, (claimed - detected) / claimed × 100%)`

3. **`get_provider_detail(provider_id, model)`** — 查该 Provider+Model 的 I/C/O 审计SUM/声称SUM（`SUM(real_input_tokens), SUM(claimed_input_tokens)... WHERE provider_id=? AND model=? GROUP BY provider_id`）

**命令改动：**

1. 新增 `get_dashboard_data` — TauriState 拿 db 锁 → 调 `get_dashboard_data()` → 返回
2. 新增 `get_provider_detail` — 接收 `provider_id`, `model` 参数
3. 新增 `get_app_config` — 返回当前 config 各字段
4. 新增 `save_app_config` — 接收 `AppConfigPayload`，写回 config
5. 修改 `list_providers` — 原直接 `list_providers()` 改为 `list_providers_with_stats()`

**步骤：**
1. Modify `provider/types.rs` — 添加 `AuditSummary` 类型（用于 Provider 的审计汇总）
2. Modify `storage/database.rs` — 添加三个方法 + SQL 聚合

4. Modify `lib.rs` — 在 `generate_handler![]` 注册新命令

### Task 6：Dashboard 数据层 — useDashboardData hook + event 订阅

**Files:**
- Create: `frontend/src/hooks/useDashboardData.ts`

**Interfaces:**
- Consumes: Task 3 的 `audit-tick` event + Task 4 的 `get_dashboard_data` 命令
- Produces: 一个 React hook，返回 `{ dashboardData, trendQueue, loading, error, refresh }`
- Consumed by: DashboardPage

**数据获取规则（严格按 PRD）：**

| 数据 | 初始加载（组件挂载时） | event 后刷新 |
|------|----------------------|-------------|
| `today_summary` | ✅ invoke | ✅ 重新 invoke |
| `model_breakdown` | ✅ invoke | ✅ 重新 invoke |
| `daily_breakdown` | ✅ invoke | ✅ 重新 invoke |
| `provider_ranking` | ✅ invoke | ✅ 重新 invoke |
| `current_audit` | **❌ null，等 event** | ✅ 重新 invoke |
| 趋势队列 | **❌ 20 个 0，等 event** | ✅ `latest_trend_point` shift/push |

**Hook 行为：**

```
组件挂载
  ├─ invoke('get_dashboard_data') → 填充 today / daily / ranking（不含 current_audit）
  ├─ 趋势队列始终初始化为 20 个 0（不管 SQLite 里有没有历史数据）
  ├─ current_audit = null（等 event 来才显示）
  ├─ 开始监听 audit-tick
  │
收到 audit-tick
  ├─ 重新 invoke('get_dashboard_data')
  ├─ 用返回的 latest_trend_point（最新 1 条）→ shift/push 入趋势队列
  ├─ current_audit ← 返回的 current_audit
  └─ 更新其他数据（today / daily / ranking）

组件卸载 → unlisten event
```

**Hook 返回值：**

```typescript
function useDashboardData(): {
  dashboardData: DashboardData | null    // today / daily / ranking（初始有）；current_audit（等 event）
  trendQueue: TrendPoint[]               // 20 条固定长度队列，初始全 0，event 后 shift/push
  loading: boolean
  error: string | null
  refresh: () => void                    // 手动刷新
}
```

**趋势队列操作（在 DashboardPage 中用）：**

```typescript
// trendQueue 在 hook 内部维护
const [trendQueue, setTrendQueue] = useState<TrendPoint[]>(Array(20).fill(zeroPoint))

// 收到 event 后：
setTrendQueue(prev => [...prev.slice(1), latestPoint])
```

**步骤：**
1. Create `frontend/src/hooks/useDashboardData.ts`
   - `invoke('get_dashboard_data')` 初始加载
   - `listen('audit-tick', cb)` 订阅 event
   - 趋势队列管理（shift/push）
   - 清理（unlisten on unmount）
2. `cd frontend && npx tsc --noEmit` 构建验证
3. Commit

### Task 7：Dashboard 图表组件 — TrendChart / ModelPieChart / BarChart7Day

- Produces: 3 个纯渲染 SVG 组件，无状态、无数据获取
- Consumed by: DashboardPage（Task 8）

**组件规格：**

#### TrendChart

| 规格 | 说明 |
|------|------|
| 输入 | `trendQueue: TrendPoint[]`（20 条，来自 useDashboardData） |
| 内部结构 | 3 个 `SubChart`（Input / Cache / Output），垂直排列 |
| 子图内容 | 审计值趋势线（粗实线）、声称值趋势线（淡/虚线）、差值区域填充（半透明） |
| Y 轴 | 动态范围（按数据最大值计算），右侧显示刻度标签 |
| 差异率 | 每个子图右下角显示最新一条的差异率（前端自算），颜色差异率 <3% 绿 / <5% 黄 / ≥5% 红 |
| 空态 | 队列全 0 时显示"暂无趋势数据" |
| 参考 | 原型 HTML 中 `renderSingleChart` 函数的渲染逻辑 |

**Catmull-Rom 平滑曲线**：原型 HTML 中使用 Catmull-Rom 插值生成平滑趋势线，TrendChart 复现相同算法（控制点计算方式一致）。

**Legend**：图表底部显示"审计值（基准）"、"声称值"、"差值区域"三条图例。

#### ModelPieChart

| 规格 | 说明 |
|------|------|
| 输入 | `data: ModelBreakdown[]`（今日各模型 I/C/O 汇总） |
| 数量 | 最多 5 个模型独立扇形，其余归入 Other（6 个扇形上限） |
| 角度 | 扇形角度 = 该模型审计 token 总量 / 今日审计总量 |
| 审计层 | 所有扇形 R_audit 固定相同，实心色 opacity 0.8，用模型自身颜色 |
| 声称层 | 同色半透明 opacity 0.25，R_claimed = max(R_audit, R_audit × 声称/审计)。声称≥审计时向外扩展（多报可见），声称<审计时 R_claimed = R_audit（被审计层覆盖，不可见） |
| 分隔 | 扇形间用白色细线分隔（stroke-width 0.8），从圆心到最外边缘 |
| 交互 | 鼠标移入某扇形/图例行 → 该扇形不变，其余扇形 opacity 降至 0.1；对应图例行背景高亮 |
| 图例 | 展示：模型名 + "审计 XXK" + "声称 XXK"，无额外颜色编码 |
| 颜色 | 每个模型分配一个固定色（预定义 8 色调色板），超出循环 |
| 空态 | 今日无数据时隐藏（不渲染） |
| 位置 | 内嵌在 TodayOverview 右部 |

#### BarChart7Day

| 规格 | 说明 |
|------|------|
| 输入 | `data: DailyBreakdown[]`（7 条） |
| 渲染 | 每天 3 根柱子（I/C/O），每根柱子实心 = 审计值，黑色虚线描框 = 声称值 |
